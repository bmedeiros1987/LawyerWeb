# Entrega mobile

## iPhone/iPad
PWA instalável primeiro:
- standalone;
- Web Push;
- badge;
- câmera/upload;
- modo responsivo premium;
- cache somente do necessário.

Um app iOS nativo poderá ser criado depois quando Share Extension, certificado local, background avançado ou outros recursos nativos justificarem o custo.

## Android
Capacitor empacotando o mesmo frontend:
- APK/AAB;
- push nativo;
- biometria;
- share target ("Compartilhar com ...");
- câmera/arquivos;
- deep links;
- offline controlado.

## Regra de produto
Web é a fonte funcional. Mobile é companion operacional; não criar uma segunda lógica de negócio.
