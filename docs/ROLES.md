# Papéis iniciais
Papéis são presets; cada escritório pode criar e ajustar os seus.

- Proprietário / Sócio administrador
- Sócio / Coordenador
- Advogado sênior
- Advogado
- Advogado associado
- Controladoria jurídica / Legal Ops
- Paralegal / Assistente
- Financeiro
- Administrativo
- Estagiário
- Somente leitura / Auditor
- Portal do cliente

Permissões podem variar por módulo, operação e processo/assunto sigiloso.
